
# THYRON Core

Camada planejada para perfis, configurações padrão, diagnóstico e recuperação. Ainda não há serviço funcional.

Princípios:
- preferências por usuário quando possível;
- configuração versionada e documentada;
- operações reversíveis;
- nenhuma elevação de privilégio implícita;
- logs sem segredos ou dados pessoais.
