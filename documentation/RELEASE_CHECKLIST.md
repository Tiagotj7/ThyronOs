# Checklist de release

- [ ] Versão e escopo declarados.
- [ ] Base Kali e versão/commit registrados.
- [ ] Manifesto de pacotes arquivado.
- [ ] Testes da VM anexados.
- [ ] Problemas conhecidos documentados.
- [ ] Licenças e atribuições revisadas.
- [ ] Hash SHA-256 publicado.
- [ ] Notas de versão atualizadas.
- [ ] ISO não foi adicionada ao Git.
- [ ] Aviso de caráter experimental claramente exibido.
