# Roadmap

O roadmap descreve intenção, não funcionalidades já concluídas.

| Marco | Entrega | Critério de saída |
|---|---|---|
| M0 | Repositório e governança | Estrutura, README, decisões e fluxo Git revisados |
| M1 | Ambiente de desenvolvimento | Diagnóstico registrado; dependências e versões documentadas |
| M2 | Identidade visual base | Logo/ativos licenciados ou originais; paleta e pacote de branding |
| M3 | GNOME base | Configuração inicial reproduzível e sessão funcional em VM |
| M4 | THYRON Desktop | Extensão/proposta de dock e painel validada na versão GNOME-alvo |
| M5 | Perfis visuais | Perfis realmente distintos; troca e restauração testadas |
| M6 | Aplicativos próprios | Style Center mínimo; Store somente após desenho seguro de integração |
| M7 | Terminal | Perfil visual e ZSH documentados e reversíveis |
| M8 | ISO Live experimental | ISO inicia em VM e passa checklist mínimo |
| M9 | Estabilização | Regressões, desempenho, acessibilidade e compatibilidade avaliados |
| M10 | 1.0 | Instalação, atualização, licenças, integridade e suporte documentados |

## Prioridade de execução

1. M0 e M1.
2. Identidade visual e pacote de branding mínimo.
3. GNOME base sem customizações frágeis.
4. Primeiro build Live pequeno.
5. Validar inicialização e sessão GNOME.
6. Iterar sobre desktop e aplicativos.
7. Avaliar instalador somente com base estável.

## Fora do primeiro marco ISO

- Instalador definitivo.
- THYRON Store completa.
- Seis estilos com todos os controles avançados.
- Personalização profunda de login/bloqueio.
- Centenas de ferramentas Kali.
- Promessas de compatibilidade universal.
