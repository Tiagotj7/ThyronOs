# Política de segurança

## Uso permitido

THYRON OS utiliza Kali Linux como base. Ferramentas de segurança devem ser usadas para aprendizado, administração de sistemas próprios, laboratórios e avaliações com autorização explícita.

## Reportar vulnerabilidades

Não publique detalhes exploráveis de uma vulnerabilidade ainda não corrigida em Issues públicas. Até existir um canal privado formal, evite incluir dados sensíveis e entre em contato com os mantenedores pelo mecanismo privado disponibilizado no perfil/organização GitHub do projeto.

## Escopo

Relate problemas relacionados ao código e aos pacotes mantidos por este repositório. Vulnerabilidades upstream devem ser encaminhadas também aos respectivos projetos.

## Princípios

- Menor privilégio.
- Dependências mínimas e rastreáveis.
- Verificação de integridade dos artefatos.
- Atualizações documentadas.
- Nenhum segredo no repositório.
